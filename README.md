
# Классификатор E. coli / Not E. coli / Uncertain по микроскопическим изображениям

Учебный прототип для тестового задания: принимает микроскопическое изображение бактерий и возвращает
**E. coli**, **Not E. coli** или **Uncertain** (модель не уверена) + степень уверенности.
Это исследовательский прототип, **не диагностический инструмент**.

## Кратко

- Данные: 1011 микроскопических изображений (окраска по Граму) из двух независимых источников; E. coli среди них: 50.
- Модель: ResNet-18 (предобучена на ImageNet), дообучена; выбранный вариант обучения: `finetune`.
- Test (пул двух источников): recall по E. coli = n/a, precision = n/a, balanced accuracy = n/a.
- Независимая проверка (обучение только на одном источнике, проверка на другом): balanced accuracy = 0.58, recall по E. coli = 1.00.
- Главное ограничение: очень мало примеров E. coli (50 на всё), поэтому оценки шумные (см. доверительные интервалы).

## Как запустить

1. Открыть блокнот `ecoli_colab.ipynb` в Google Colab, включить GPU (T4).
2. Запустить ячейки 1-9 сверху вниз. Ячейка 2 подключает наборы данных (Kaggle: Multi-Organism Bacterial Imaging Dataset и DIBaS).
3. Ячейка 8 запускает интерфейс (Gradio), ячейка 9 сохраняет модель и таблицы, ячейка 10 собирает эти документы.

Зависимости: `torch`, `torchvision`, `scikit-learn`, `pandas`, `pillow`, `gradio`, `kagglehub`. Random seed = 42.

## Проверка данных

- **Дубликаты.** Перцептивный хэш (DCT, 64 бита), порог Хэмминга ≤ 6. Групп почти-дубликатов: 11 (картинок в них: 22).
  Групп с обоими классами было 3; идентичные копии с разными метками (ошибка разметки) удалены: 3 шт.
  Остальные совпадения хэша — похожие по виду снимки, они просто остаются в одной части разбиения.
- **Проверка на «читерские» признаки.** Классификатор, которому доступны только метаданные (размер, цвет, яркость, контраст, резкость, яркость фона), обучен отдельно на каждом источнике (групповая кросс-валидация). AUC: dibas: 0.96, multi: 0.64. Значение около 0.5 означает, что класс по таким признакам не угадать; заметно выше — что классы различаются техническими признаками съёмки.
- **Пересечение источников.** Картинок из DIBaS, почти совпадающих с картинками multi (Хэмминг ≤ 6): 0.
- **Разбиение** 60/20/20 по группам дубликатов, стратификация по источнику и виду (`StratifiedGroupKFold`), одна и та же картинка не может попасть в train и test.

## Модель и обучение

- ResNet-18 с весами ImageNet, выход на 2 класса; вход 320×320. Все снимки один раз приводятся к этому размеру и хранятся в памяти.
- Аугментации: случайный кроп, отражения, повороты, небольшой цветовой джиттер, редкий перевод в оттенки серого (чтобы модель меньше опиралась на оттенок окраски).
- Дисбаланс классов: взвешенная функция потерь.
- Два варианта: только последний слой (`head_only`) и «последний слой, затем вся сеть с малым lr» (`finetune`). Эпоха и вариант выбираются **только по валидации** (среднее AUC и balanced accuracy).

| Вариант | Параметры | val AUC на лучшей эпохе | Балл выбора | Temperature | tau |
|---|---|---|---|---|---|
| head_only | {'epochs_head': 12, 'epochs_ft': 0} | 0.820 | 0.780 | 0.70 | 0.8 |
| finetune | {'epochs_head': 3, 'epochs_ft': 9, 'lr_ft': 3e-05} | 0.911 | 0.902 | 0.95 | 0.8 |

Выбран вариант `finetune`.

## Правило Uncertain

После softmax (с температурой, подобранной на val для более честной уверенности): `confidence = max(p, 1 - p)`.
Если `confidence < tau`, программа отвечает **Uncertain** и объясняет причину. Порог tau = **0.8** выбран на валидации:
наименьший порог не ниже 0.70, при котором точность среди принятых ≥ 95 % и принимается ≥ 80 % картинок.
Также Uncertain возвращается для слишком маленьких изображений (< 96 px).
Ограничение: правило по уверенности не гарантирует, что модель заметит совсем «чужое» изображение (не микроскопию).

## Ограничения

- Мало данных: всего 50 изображений E. coli; доверительные интервалы широкие.
- Метки на уровне вида; штаммы и условия съёмки неизвестны.
- Все изображения приведены к квадрату 320×320 (у DIBaS исходное соотношение сторон другое).
- Два набора окрашены по Граму; на снимках без окраски или с другим увеличением качество не проверялось.
- Uncertain по уверенности не ловит все «чужие» изображения.

## Что можно улучшить

- Больше независимых источников и проверка «оставить один источник для теста» для каждого.
- Визуализация того, на что смотрит модель (Grad-CAM), чтобы убедиться, что это бактерии, а не фон.
- Явный детектор «это не микроскопия» (расстояние в пространстве признаков) для более надёжного Uncertain.
- Калибровка порога на большем валидационном наборе.

## Ответ на дополнительный вопрос: 98 % accuracy на внутреннем test — значит ли, что модель хорошо распознаёт E. coli?

**Нет, не значит.**

1. Внутренний test взят из того же источника, что и обучение (одна камера, окраска, фон). Если классы различаются техническими признаками или дубликаты попали в разные части, модель выучит «признаки набора», а не бактерию, и accuracy этого не покажет.
2. При дисбалансе классов высокая accuracy возможна при плохом recall по E. coli. Нужны recall/precision для E. coli, PR-AUC и матрица ошибок.
3. Маленький test даёт широкий доверительный интервал: при ~100 картинках 98 % — это около 2 ошибок.
4. Внутренний test не проверяет виды и условия съёмки, которых не было в обучении.

Как проверить: независимый источник, не участвовавший ни в обучении, ни в подборе параметров; разбиение по группам дубликатов и по источникам; проверка «читерских» признаков; метрики по E. coli с доверительными интервалами и разбор ошибок по видам; в идеале новые снимки из другой лаборатории.
